# Модель для распознавания пород котов по фото
## Модель
- Дообученная с регуляризацией ConvNeXt-Tiny (1K параметров)

## Датасет
- `47679` изображений
- `66` пород
- `>3K` изображений для каждой
- Исключены "псевдопороды" -- окраски и беспородные 

Использованы следующие датасеты:
1. https://www.kaggle.com/datasets/nikolasgegenava/cat-breeds
2. https://www.kaggle.com/datasets/solothok/cat-breed
3. https://www.kaggle.com/datasets/ma7555/cat-breeds-dataset
